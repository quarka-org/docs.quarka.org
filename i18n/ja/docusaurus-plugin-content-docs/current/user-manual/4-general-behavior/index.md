# 基本仕様

QA Assistants の基本的な動作仕様や、データ収集・更新に関する挙動について説明します。


## 計測対象

### ログインユーザーの扱い

ログイン中の WordPress ユーザーは、デフォルトで計測対象から除外されます。


### フォーム入力内容の扱い

フォーム入力内容やパスワードなどの入力データは収集されません。  


---

## データ収集制限

QA Assistants では、月間PV数の上限が設定されています。  
上限に達した場合、それ以降に収集されたデータは保存されません。  
月間PV数のカウントは、毎月1日に自動的にリセットされます。  
上限値は設定ファイルから変更できます。 
詳細は[qa-config.php を設定する](/docs/user-manual/getting-started/configure-qa-config)をご覧ください。
