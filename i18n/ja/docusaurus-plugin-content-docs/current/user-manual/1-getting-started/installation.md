# インストール

QA Assistants は、WordPress プラグインとしてインストールできます。

## インストール方法

1. WordPress 管理画面にログインします  
2. **プラグイン** → **新規追加** を開きます  
3. 「QA Assistants」を検索します  
4. **今すぐインストール** をクリックします  
5. インストール完了後、**有効化** をクリックします  

---

## 動作確認

インストール後、以下の手順で計測動作を確認できます。

1. シークレットウィンドウなど、ログアウト状態のブラウザでサイトへアクセスします  
2. WordPress 管理画面へ戻ります  
3. **QA Assistants** → **リアルタイム** を開きます  

アクセス中のデータが表示されれば、正常に動作しています。  

※ログイン中の WordPress ユーザーは、デフォルトで計測対象から除外されます。

---

## アドバンスモード（オプション）

アドバンスモードを有効化すると、より詳細な分析メニューやレポートを利用できます。

1. **QA Assistants** → **設定** を開きます  
2. **アドバンスモード** を有効化します  
3. **変更を保存** をクリックします
