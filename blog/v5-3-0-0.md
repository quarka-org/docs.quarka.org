QA Assistants 5.3.0.0 improves the readability and usability of report screens.

This release also adds support for collecting Google Search Console data and expands the foundation for using a wider range of assistants.

<!-- truncate -->

## Clearer and Easier-to-Use Reports

We have improved the charts, tables, and date range selection on report screens.

* Redesigned charts to make changes in your data easier to understand
* Added total rows to report tables
* Added controls for choosing which columns to display
* Redesigned the date range calendar to make navigating between months and years and selecting a period easier

## Support for Collecting Google Search Console Data

QA Assistants can now connect to Google Search Console and collect data through its API.

After you set up the connection and the data has been collected, compatible assistants can use search queries, impressions, clicks, average positions, and other Search Console data.

At this time, QA Assistants does not include a dedicated report screen for viewing Search Console data directly.

## Support for a Wider Range of Assistants

We have expanded the functionality available to assistants created with tools such as Assistant Maker.

Compatible assistants can now offer features such as date range selection, charts and scorecards, and analysis using WordPress post data.

## System Requirements

Starting with QA Assistants 5.3.0.0, the minimum required PHP version is PHP 7.4.

Before updating, please make sure that your server is running PHP 7.4 or later.
