QA Assistants 5.3.0.3 includes security fixes for session replay and admin page rendering.
It also fixes an issue that could prevent reports from updating.

Please update to the latest version as soon as possible.

<!-- truncate -->

## Fixed an issue preventing report updates

On PHP 8, visits with certain URL parameter formats could stop nightly data processing and prevent reports from updating.
This issue has been fixed.

## Changes to session replay display

For improved security, page scripts are now restricted during replay.

Some fonts or icons may display incorrectly, and some visual effects may not be reproduced.
These changes affect playback only. Recorded data is not affected.
